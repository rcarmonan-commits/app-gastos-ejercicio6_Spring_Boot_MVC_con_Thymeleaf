Proyecto Ejercicio 6 - Gestión de Gastos

Esta aplicación fue desarrollada como parte de la Unidad 2 de la asignatura de Desarrollo Web. Su propósito principal es evidenciar la transición de una arquitectura tradicional de Servlets/JSP hacia un entorno moderno basado en el framework Spring Boot MVC.

Características Principales

  • Spring Boot MVC: Desarrollo web basado en el framework Spring, reemplazando el uso directo de Servlets y JSP.
  • Spring Data JPA: Mapeo relacional de objetos (ORM) y persistencia de datos (reemplazando JDBC puro).
  • Thymeleaf: Generación de vistas del lado del servidor (reemplazando a JSP).
  • Arquitectura por Capas: Separación estricta entre Modelos, Repositorios (JPA), Servicios y Controladores.

Estructura del Proyecto

  • src/main/java/com/ejercicio6/gastos/model/: Entidades mapeadas con JPA (@Entity).
  • src/main/java/com/ejercicio6/gastos/repository/: Interfaces JpaRepository para el acceso a datos.
  • src/main/java/com/ejercicio6/gastos/service/: Lógica de negocio.
  • src/main/java/com/ejercicio6/gastos/controller/: Controladores Spring MVC (@Controller) que manejan las peticiones.
  • src/main/resources/templates/: Plantillas HTML de Thymeleaf para las vistas.
